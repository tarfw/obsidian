# Jev reference folder

The canonical Jev programming reference is [jev.md](jev.md). The researched
application study is [tarjevplan.md](tarjevplan.md). The final TAR architecture is
[tarv12.md](../tarv12.md). This folder supplies research and examples, while v12
owns architecture and rollout decisions.

~~~text
jev.md                 single complete TAR Jev reference
tarjevplan.md           historical application and simplification study
agentrun-plan.md        workflow promotion pilot informed by AgentRun posts
README.md              source-library map
sources.md             current primary and community sources
~~~

Read [jev.md](jev.md) first. Use [sources.md](sources.md) to verify a provider claim
or find the live source.
