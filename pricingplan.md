# Tar Pricing

One credit wallet pays for owned workspaces and AI agents. There are no fixed plans or workspace limits.

## 1. Workspaces and Credits

| Workspace usage | Credits |
|---|---:|
| Personal workspace | 0 |
| Each active owned workspace | 100/month |
| Joined workspace | 0 for the member |
| Public browsing, ordering, or booking | 0 |
| Archived workspace | 0 |

Monthly workspace credits are reserved first. AI automation inside a workspace uses its owner's wallet.

## 2. Agents and Credits

| Agent action | Credits |
|---|---:|
| Workspace answer or summary | 2 |
| Sales or support reply | 2 |
| Quote or proposal | 10 |
| Operations workflow | 10 |
| Analyst or tax report | 20 |
| Keep a public site active | 50/month |
| Generate a site draft | 100/run |
| Edit a site section | 10/run |
| Publish or update a site | 5/run |
| OCR document scan | 3/page |
| Voice note to order | 5 |
| Bill audit | 5/bill |
| Competitor price check | 2/product/source |
| Customer retention campaign | 20 |
| Verified lead batch | 50 |
| Product photo cleanup | 10/image |
| Deep research swarm | 100/task |

Manual actions and normal database operations use 0 credits. Site-agent actions are charged only when called.

## 3. Credits and Cost

| Credit pack | Indicative price* |
|---|---:|
| 500 credits | ₹99 |
| 2,500 credits | ₹449 |
| 6,000 credits | ₹999 |

\* Prices are localized worldwide using purchasing power, taxes, and store costs. Purchased credits do not expire while the account is active. Third-party charges such as WhatsApp, SMS, domains, and payment processing are separate.
